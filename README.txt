Planner v0.9.41

Подзадачи создаются без даты: название, заметка и выполнение.
«Добавить в календарь» открывает расписание с датой, началом и концом.
Отмена расписания оставляет подзадачу в папке без даты. Уже существующие
расписания сохраняются. Ночной блок может завершаться утром следующего дня.

«На следующий день» переносит незавершённый блок, сохраняя заметку,
время и принадлежность задаче. Предыдущий блок отмечается перенесённым;
готовность основной задачи учитывает последнюю запись цепочки один раз.

«Удалить подзадачу» удаляет заметку и цепочку её переносов после подтверждения.
История записанного времени сохраняется. В папке есть «Изменить задачу»:
название, тип, цвет, описание и архив. IDs и существующие данные сохраняются.

Для обновления GitHub распакуйте все 6 файлов архива в корень сайта с заменой.
Ключ данных и схема не менялись. Перед обновлением рекомендуется штатный экспорт.
Сервис-воркер обновлён для получения новой версии.

Автоматические проверки пройдены: подзадачи/черновики/удаление/переносы,
календарь, прогресс и редактирование задач, аналитика, обучение, портфолио,
аккаунт, фото, темы и восстановление соединения.
Визуальная проверка в браузере и на реальном iPhone не выполнялась.
