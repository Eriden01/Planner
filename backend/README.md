# Серверная часть

Planner использует Supabase для входа в аккаунт и синхронизации данных. Отдельный сервер для локального запуска приложения не требуется.

Клиент работает с таблицей `planner_state`. В запросах используются поля `user_id`, `data`, `updated_at`, `device_id` и `version`; доступ к строкам должен ограничиваться политиками Row Level Security в проекте Supabase. Настройка базы данных и её политики выполняются в самом проекте Supabase.
